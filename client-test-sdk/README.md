# A2A SDK Client UI

Browser-based test client using the official **@a2a-js/sdk** to test OpenDirect Buyer and Seller agents.

## Features

- Uses official `@a2a-js/sdk/client` with `ClientFactory`
- Beautiful responsive UI with chat interface
- Real-time task monitoring and status updates
- Debug console for tracking A2A protocol interactions
- Quick action buttons for common operations

## Setup

```bash
# Install dependencies
npm install

# Build the client
npm run build
```

## Running

```bash
# Serve the client (opens on http://localhost:8081)
npm run serve

# Or use Python HTTP server
python3 -m http.server 8081
```

Then open http://localhost:8081 in your browser.

## Development

```bash
# Watch mode with auto-rebuild
npm run dev
```

## Usage

1. Select agent type (Buyer or Seller)
2. Click "Connect" to connect via @a2a-js/sdk ClientFactory
3. Send messages to test agent capabilities
4. Monitor tasks and view agent responses in real-time

## Architecture

- **index.html** - UI structure
- **style.css** - Modern, responsive styling
- **src/app.js** - Client implementation using @a2a-js/sdk
- **dist/bundle.js** - Bundled JavaScript (generated by esbuild)

## Key SDK Methods Used

- `ClientFactory.createFromUrl(agentCardUrl, apiKey)` - Create A2A client from agent card
- `client.sendMessage({ message })` - Send message to agent
- `client.getTask({ taskId })` - Poll task status and get responses

## Comparison with Manual Client

| Feature | SDK Client (this) | Manual Client |
|---------|------------------|---------------|
| A2A SDK | ✅ @a2a-js/sdk | ❌ Plain fetch |
| Protocol Compliance | ✅ Guaranteed | ⚠️ Manual |
| Maintenance | ✅ Auto-updates | ❌ Manual |
| Type Safety | ✅ SDK types | ❌ None |

- Task creation and status polling
